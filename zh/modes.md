# 工作模式

Pushdozer 提供 **8 种**面向玩家的工作模式，按 `G` 键循环切换。每种模式在配置界面中都有独立的 **Config** 子面板。

> **执行方式**：主手或副手持有推土机，对准目标位置 **右键点击**。快捷键只切换设置，不会直接修改地形。

## 玩家视角总览

| 模式 | 改变高度 | 改变材质 | 生成植被 | 典型用途 |
|------|:--------:|:--------:|:--------:|----------|
| 挖掘 | — | 删除方块 | — | 清方、开洞、平整 |
| 铺设 | 可选填充 | 是 | — | 填坑、铺地表 |
| 平滑（4 变体） | 是 | 可能重建表层 | — | 整平、抬升/下切 |
| 表面粗糙 | 是 | 可能重建表层 | — | 自然化人工平整面 |
| 表层转换 | 否 | 是 | — | 混合草/沙/石等材质 |
| 撒骨粉 | 视生长 | 视结果 | 可促进 | 催熟作物与植被 |
| 批量种植 | — | — | 是 | 造林、补植被 |
| 水岸处理 | 通常否 | 是 | 可选 | 河岸/湖岸自然化 |

**G 键循环顺序**：挖掘 → 铺设 → 平滑 → 表面粗糙 → 表层转换 → 撒骨粉 → 批量种植 → 水岸处理

---

## 挖掘模式（Excavate）

**做什么**：删除笔刷范围内的方块，替换为空气。

### 怎么操作

1. 选择 **挖掘** 模式
2. 点击 **选择允许被破坏的方块**，至少勾选一种方块类型
3. 选择笔刷形状与尺寸，设置标高（可选）
4. 右键目标位置

### 标高限制

| 标高模式 | 可挖掘范围 |
|----------|-----------|
| 标高不限 | 任意高度 |
| 跟随玩家 | Y ≥ 玩家脚下高度 |
| 锁定 / 自定义 | Y ≥ 锁定标高 + 1 |

超出标高范围的方块会被 **静默跳过**，不会弹出提示。

### 常见误区

- **白名单默认为空**——未选择可破坏方块时，挖掘不会有任何效果
- 不可破坏方块（硬度 &lt; 0，如基岩）始终跳过，与是否在白名单中无关
- **忽略列表**中的方块（可在配置中设置）不会被破坏
- 空气方块不会被「挖掘」

### 推荐参数

| 场景 | 笔刷 | 标高 |
|------|------|------|
| 平整地基 | 长方体 10×10×3 | 锁定玩家标高 |
| 水平隧道 | 长方体 4×4×4 | 标高不限 |
| 清除表层植被 | 球体，小半径 | 跟随玩家 |

## 铺设模式（Place）

**做什么**：在笔刷范围内用自然方块填充空气和可替换的软方块。

### 怎么操作

1. 选择 **铺设** 模式
2. 选择铺设方式：**自适应生物群系** 或 **选择自然方块**
3. 右键目标区域

### 铺设方式

| 方式 | 说明 |
|------|------|
| **自适应生物群系** | 根据生物群系与上下文自动选块（如熔岩旁铺石头、沙旁铺砂岩） |
| **选择自然方块** | 手动指定一种自然方块 |

### 标高限制

| 标高模式 | 可铺设范围 |
|----------|-----------|
| 标高不限 | 任意高度 |
| 跟随玩家 | Y ≤ 玩家脚下高度 − 1 |
| 锁定 / 自定义 | Y ≤ 锁定标高 |

### 常见误区

- 铺设不会替换已有固体方块（除非该方块在替换规则中，如装饰性植物）
- 标高限制与挖掘相反：铺设在标高 **以下**，挖掘在标高 **以上**

### 推荐参数

| 场景 | 方式 | 标高 |
|------|------|------|
| 快速铺地表 | 自适应生物群系 | 锁定玩家标高 |
| 人工平台 | 指定自然方块 | 锁定 / 自定义 |

## 平滑模式（Smooth）

**做什么**：在笔刷范围内重塑地形高度；表层方块可能随高度变化而重建。

### 怎么操作

1. 选择 **平滑** 模式，点击 **Config**
2. 选择 4 种变体之一（单选）
3. 调整强度参数
4. 右键目标区域；可多次操作逐步调整

### 四种变体

| 变体 | 算法要点 | 适用 |
|------|----------|------|
| **标准平滑** | 空间高斯模糊，单次变化幅度较大 | 大面积整平、去小起伏 |
| **自适应平滑** | 多尺度双边滤波，保留大地形轮廓 | 山体柔化、去细碎噪声 |
| **提升** | 笔刷中心高斯隆起 | 局部抬升、造小丘 |
| **降低** | 笔刷中心凹陷 | 局部下切、造洼地 |

鼠标悬停在各变体按钮上可查看详细说明（tooltip）。

### 强度参数

| 参数 | 范围 | 适用变体 |
|------|------|----------|
| 平滑强度 | 0.1–1.0 | 标准、自适应 |
| 抬升/降低深度 | 0.1–1.0 | 提升、降低 |

### 标高限制

平滑模式遵循通用标高过滤（见 [标高系统](height.md)）。

### 常见误区

- 标准平滑单次变化比自适应更大，大范围操作可能改变整体轮廓
- 提升/降低是方向性操作，不是全区域均匀抬升

### 推荐参数

| 场景 | 变体 | 强度 |
|------|------|------|
| 建筑用地整平 | 标准 | 0.5–0.8 |
| 保留山形去噪 | 自适应 | 0.3–0.5 |
| 造小丘 | 提升 | 0.3–0.6 |
| 造洼地 | 降低 | 0.3–0.6 |

## 表面粗糙（Surface Roughen）

**做什么**：先向平滑基准重塑，再叠加 Perlin 噪声，为过于平整的地表添加自然起伏。

### 怎么操作

1. 选择 **表面粗糙**，点击 **Config**
2. 调整粗糙强度与重塑强度
3. 右键目标区域

### 参数说明

| 参数 | 范围 | 说明 |
|------|------|------|
| **粗糙强度** | 0.1–2.0 | 噪声峰值；1.0 ≈ ±5 格（材质系数另计） |
| **平滑强度（重塑）** | 0.1–1.0 | 加噪声前向平滑基准靠拢的程度 |
| **自动缩放** | 开/关 | 默认开启，按笔刷半径自动调整噪声 |

关闭 **自动缩放** 后可手动调整噪声频率、持久性、八度数。面板底部 **重置** 恢复默认。

### 标高限制

遵循通用标高过滤。

### 常见误区

- 与平滑模式不同：表面粗糙 **刻意添加** 噪声，而非消除起伏
- 高粗糙强度在大笔刷上可能产生剧烈地形变化

### 推荐参数

| 场景 | 粗糙强度 | 重塑强度 |
|------|----------|----------|
| 轻微自然化 | 0.3–0.5 | 0.3 |
| 明显起伏 | 0.7–1.0 | 0.5 |

## 表层转换（Surface Convert）

**做什么**：按配置比例替换笔刷范围内地表列的方块材质，**不改变 Y 坐标**。

### 怎么操作

1. 选择 **表层转换**，点击 **Config**
2. 添加最多 5 种方块并设置占比
3. 选择分布模式
4. 右键目标区域

### 方块与分布

| 选项 | 说明 |
|------|------|
| 方块列表 | 最多 5 种，各自设置占比；默认草方块 100% |
| **自然斑块** | 固定种子 Perlin 噪声形成连贯斑块 |
| **随机散布** | 每列独立随机 |
| **允许人工方块** | 默认关闭；容器与方块实体始终受保护 |

### 标高限制

遵循通用标高过滤；仅替换地表列方块。

### 常见误区

- 无有效目标方块时操作被跳过，并提示「表层转换已跳过」
- 不会挖掘或填方，只换材质

### 推荐参数

| 场景 | 方块 | 分布 |
|------|------|------|
| 草地斑驳 | 草 60% + 泥土 40% | 自然斑块 |
| 均匀混合 | 多种方块均分 | 随机散布 |

## 撒骨粉（Bone Meal）

**做什么**：对笔刷范围内符合条件的植物施加骨粉效果，促进生长。

### 怎么操作

1. 选择 **撒骨粉** 模式（无额外 Config 面板）
2. 右键目标区域

### 作用对象

- 草方块、泥土、耕地、沙子上的植被
- 草、花、作物、树苗等可骨粉催熟的植物
- 大范围操作分批处理（每 tick 约 48 个位置）

### 标高限制

遵循通用标高过滤。

### 常见误区

- 对非植物方块或不可骨粉方块无效果
- 可能触发树木生长，变更范围大于笔刷本身（撤销会记录实际变更）

### 推荐参数

| 场景 | 笔刷 |
|------|------|
| 催熟作物 | 长方体，覆盖农田 |
| 快速绿化 | 球体，中等半径 |

## 批量种植（Batch Plant）

**做什么**：在笔刷范围内按密度与团簇参数批量生成植物。

### 怎么操作

1. 选择 **批量种植**，点击 **Config**
2. 选择种植类型与参数
3. 右键目标区域

### 种植类型

| 类型 | 说明 |
|------|------|
| **树木** | 可选树种或 **生物群系自适应**；调用 Minecraft 树生成器 |
| **花朵** | 可选花组或 **生物群系自适应** |
| **草类** | 种植草、蕨类等低矮植被 |
| **自定义** | 从植物列表自由选择；列表为空时使用默认植物 |

### 其他参数

| 参数 | 范围 | 说明 |
|------|------|------|
| 种植密度 | 10–100% | 单位面积内植物出现概率 |
| 团簇大小 | 可调 | 控制空间聚集程度（树木与花草算法不同） |

配置文件中的 **遵守生物群系**（`respectBiomes`）默认为开启，但 UI 未暴露此选项。

### 标高限制

遵循通用标高过滤；植物需落在有效地表上。

### 常见误区

- 密度过低可能几乎不生成植物
- 树木模式需要足够空间（上方无遮挡）

### 推荐参数

| 场景 | 类型 | 密度 | 团簇 |
|------|------|------|------|
| 稀疏森林 | 树木，生物群系自适应 | 30–40% | 默认 |
| 花田 | 花朵，平原花卉 | 50–70% | 中等 |
| 草甸 | 草类 | 40–60% | 默认 |

## 水岸处理（Shoreline Process）

**做什么**：检测笔刷范围内的水边，从水面向内陆按水平距离混合地表材质；可选种植植被。**不改变地形高度**。

### 怎么操作

1. 选择 **水岸处理**，点击 **Config**
2. 选择水岸类型与宽度
3. 右键水域边缘

### 水岸类型

| 类型 | 说明 |
|------|------|
| **沙滩** | 沙子过渡，适合海洋和湖泊 |
| **堤岸** | 泥土/草方块过渡 |
| **自适应** | 按生物群系自动选择（如沙漠红沙、雪地雪块） |
| **泥泞** | 沼泽风格 |
| **岩石** | 岩石质水岸 |
| **自定义** | 自选方块与植物 |

### 其他参数

| 参数 | 范围 | 说明 |
|------|------|------|
| 水岸宽度 | 1–10 格 | 距水边的水平过渡距离 |
| 植被种植 | 开/关 | 自定义类型除外 |
| 植被密度 | 0–100% | 水岸区域植物密度 |
| 标高以上/以下 | 互斥 | 需先设置非「标高不限」的标高模式 |

### 常见误区

- 笔刷需覆盖 **水边交界区域**，仅点击深水可能无效果
- 不会改变岸坡形态，只替换表层方块

### 推荐参数

| 场景 | 类型 | 宽度 |
|------|------|------|
| 湖泊沙滩 | 沙滩 | 3–4 |
| 河流自然岸 | 自适应 | 3–5 |
| 沼泽 | 泥泞 | 4–6 |

> 各水岸类型的材质与生物群系适配规则详见 [水岸预设详解](shoreline.md)。分步操作见 [操作教程](workflows.md)。
