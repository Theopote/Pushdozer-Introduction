# 参数调优指南

各工作模式关键参数的效果、推荐范围与组合建议。默认值见 [参考手册](reference.md)。

---

## 通用原则

| 原则 | 说明 |
|------|------|
| 先小后大 | 笔刷尺寸和强度都从较小值开始，逐步增加 |
| 先预览后执行 | 用线框确认范围，避免误操作 |
| 分步叠加 | 大范围分多次右键，便于撤销 |
| 模式组合 | 粗加工 → 平滑 → 粗糙 → 表层/种植 |

---

## 挖掘模式

| 参数 | 范围 | 调优建议 |
|------|------|----------|
| 笔刷尺寸 | 1–64 | 平整用大长方体；精细用小型号 |
| 白名单 | — | 只选需要清除的方块，避免误删贵重方块 |
| 标高 | — | 水平切割用 **锁定**；隧道用 **不限** |
| 操作距离 | 1–99 | 远距离作业增大至 30–40 |

**常见组合**：锁定标高 + 长方体(长×宽×高 3) + 泥土/石头白名单

---

## 铺设模式

| 参数 | 效果 |
|------|------|
| **自适应生物群系** | 根据下方地面和生物群系选方块（草方块/泥土/沙子/下界岩等） |
| **指定自然方块** | 始终使用同一种方块 |

| 场景 | 推荐 |
|------|------|
| 自然修复 | 自适应生物群系 |
| 人工平台（石头） | 指定石头 |
| 填平到水平 | 锁定标高 + 自适应 |

**自适应逻辑摘要**：
- 下方为泥土类 + 上方空气 → 草方块；否则 → 泥土
- 下方为沙子/石头 → 保留同类型
- 下界 → 下界岩
- 其他 → 生物群系默认顶层方块

## 平滑模式

### 变体选择

| 变体 | 强度建议 | 笔刷建议 | 适用 |
|------|----------|----------|------|
| 标准平滑 | 0.5–0.8 | 中–大球体/长方体 | 大面积整平 |
| 自适应平滑 | 0.3–0.5 | 中等 | 保留山脊与谷地 |
| 提升 | 0.3–0.6 | 小–中球体 | 局部抬升，可多次叠加 |
| 降低 | 0.3–0.6 | 小–中球体 | 局部下切 |

### 平滑强度（0.1–1.0）

| 值 | 效果 |
|----|------|
| 0.1–0.3 | 微调，几乎不可见 |
| 0.4–0.6 | 常规编辑，推荐起点 |
| 0.7–0.9 | 强烈变化，可能过度平滑 |
| 1.0 | 单次最大变化 |

**提示**：标准平滑单次变化大于自适应；精细修整请降低强度或换用小笔刷。

## 表面粗糙

| 参数 | 范围 | 效果 |
|------|------|------|
| 粗糙强度 | 0.1–2.0 | 1.0 ≈ ±5 格峰值（材质系数另计） |
| 平滑重塑 | 0–1 | 0=保留原貌，1=完全向平滑基准靠拢 |
| 自动缩放 | 开/关 | 开启时根据笔刷半径自动调噪声 |

### 手动噪声（自动缩放关闭）

| 参数 | 范围 | 调高效果 | 调低效果 |
|------|------|----------|----------|
| 频率 | 0.01–0.15 | 更细碎的起伏 | 更平缓的大波浪 |
| 持久性 | 0.05–0.95 | 更复杂、多层次 | 更单一、平滑 |
| 八度数 | 1–6 | 更多细节（略耗性能） | 更简单 |

### 推荐组合

| 目标 | 粗糙 | 重塑 | 自动缩放 |
|------|------|------|----------|
| 轻微自然化 | 0.3–0.5 | 0.2–0.4 | 开 |
| 明显起伏 | 0.8–1.2 | 0.3–0.5 | 开 |
| 精细控制 | 0.5 | 0.5 | 关，手动调频率 |

## 表层转换

| 参数 | 建议 |
|------|------|
| 方块数量 | 2–3 种最自然；5 种适合复杂混合 |
| 占比 | 主材质 50–70%，副材质 15–30%，点缀 5–10% |
| 分布 | 自然过渡用 **斑块**；均匀混合用 **散布** |
| 人工方块 | 默认关；改造建筑区时可开 |
| 笔刷 | 中等尺寸，多次重叠消除边界 |

**示例配比**：
- 草甸：草 60% + 泥土 25% + 粗泥 15%
- 沙漠边缘：沙 70% + 红沙 20% + 砂岩 10%
- 雪原混合：雪 50% + 冰 30% + 石头 20%

## 批量种植

| 参数 | 范围 | 效果 |
|------|------|------|
| 种植密度 | 10–100% | 越高越密集 |
| 团簇大小 | 低–高 | 越高越分散，越低越成片 |

| 场景 | 密度 | 团簇 | 类型 |
|------|------|------|------|
| 稀疏森林 | 20–30% | 中 | 树木·生物群系自适应 |
| 密林 | 50–70% | 低 | 树木·指定树种 |
| 花田 | 40–60% | 高 | 花朵·平原花卉 |
| 草地 | 30–50% | 中 | 草类 |

---

## 水岸处理

| 参数 | 建议 |
|------|------|
| 类型 | 不确定时用 **自适应** |
| 宽度 | 小水体 2–3；海洋 4–6；沼泽 5–7 |
| 植被密度 | 沙滩 10–15%；河流 20%；沼泽 25–30% |
| 笔刷高度 | 1–2，避免误改远离水面的高地 |

详见 [水岸预设详解](shoreline.md)。

---

## 显示与距离

| 参数 | 建议 |
|------|------|
| 线框 | 日常默认，性能最好 |
| 点云 | 预览表面处理效果 |
| 表面 | 需要看清体积时使用 |
| 不显示 | 熟练操作或录制视频 |
| 操作距离 | 近处精修 10–15；远处作业 30–50 |

## 标高

| 任务 | 模式 |
|------|------|
| 水平切割/填充 | 锁定玩家标高 |
| 多层楼 | 自定义 Y |
| 边走边修 | 跟随玩家 |
| 3D 自由编辑 | 标高不限 |

详见 [标高系统](height.md)。

## 问题诊断

| 现象 | 可能原因 | 调整 |
|------|----------|------|
| 挖掘无效果 | 白名单为空 | 选择可破坏方块 |
| 平滑过度 | 强度太高 | 降至 0.3–0.5 或换自适应 |
| 粗糙太剧烈 | 粗糙强度 > 1 | 降至 0.3–0.6 |
| 表层边界明显 | 笔刷太大或只刷一次 | 小笔刷多次重叠 |
| 树木不生成 | 地面不可种植 | 先铺设再种植 |
| 水岸无变化 | 笔刷未覆盖水边 | 缩小高度，贴近水面 |
