# 配置界面详解

按 `K` 打开 **推土机配置** 界面（主手或副手持有推土机均可）。也可通过 **ModMenu** 进入（需安装 [ModMenu](https://modrinth.com/mod/modmenu)，可选依赖；ModMenu 入口无需手持工具）。

### ModMenu 入口

1. 主菜单 → **Mods（模组）**
2. 找到 **Pushdozer** → 点击配置按钮
3. 打开与 `K` 键相同的配置界面

---

## 主界面布局

主界面固定在屏幕左侧，从上到下包含以下控件：

| # | 控件 | 操作 | 说明 |
|---|------|------|------|
| 1 | **笔刷形状** 下拉按钮 | 点击展开 | 选择 8 种几何体之一 |
| 2 | **Config**（笔刷旁） | 点击 | 打开当前几何体的尺寸子面板 |
| 3 | **工作模式** 下拉按钮 | 点击展开 | 选择 8 种工作模式之一 |
| 4 | **Config**（模式旁） | 点击 | 打开当前模式的专属配置子面板 |
| 5 | **显示模式** 按钮 | 点击循环 | 切换预览方式；也可按 `V` |
| 6 | **最大操作距离** 滑动条 | 拖动 | 1–99，默认 20；也可按 `↑`/`↓` |
| 7 | **标高配置** 按钮 | 点击 | 打开标高模式子面板 |
| 8 | **保存并关闭** 按钮 | 点击 | 保存配置到本地并同步到服务端 |

> 切换工作模式或几何体时，屏幕上方会短暂显示提示消息。

---

## 笔刷形状选择面板

点击 **笔刷形状** 按钮弹出居中面板，列出全部 8 种几何体。点击一项即可选中并关闭面板。

`U` 键按以下顺序循环切换：

**球体 → 长方体 → 正八面体 → 圆柱体 → 圆锥体 → 椭球体 → 正四面体 → 三棱柱**

---

## 几何体 Config 子面板

每种几何体有独立子面板，滑动条范围均为 **1–64**：

| 几何体 | 滑动条 | 对应配置字段 |
|--------|--------|-------------|
| 球体 | 半径 | `sphereRadius` |
| 长方体 | 长度、宽度、高度 | `length`, `width`, `boxHeight` |
| 正八面体 | 半径 | `octahedronRadius` |
| 圆柱体 | 半径、高度 | `cylinderRadius`, `cylinderHeight` |
| 圆锥体 | 半径、高度 | `coneRadius`, `coneHeight` |
| 椭球体 | 长度、宽度、高度 | `length`, `width`, `ellipsoidHeight` |
| 正四面体 | 边长 | `tetrahedronEdgeLength` |
| 三棱柱 | 边长、高度 | `triangularPrismSideLength`, `triangularPrismHeight` |

子面板底部 **完成** 按钮保存并关闭。

---

## 工作模式选择面板

点击 **工作模式** 按钮弹出居中面板。`G` 键按以下顺序循环：

**挖掘 → 铺设 → 平滑 → 表面粗糙 → 表层转换 → 撒骨粉 → 批量种植 → 水岸处理**

> 旧版独立的「平滑提升」「平滑降低」「自适应平滑」已合并到 **平滑** 模式的变体选项中。

---

## 各模式 Config 子面板控件

### 挖掘模式

| 控件 | 说明 |
|------|------|
| **选择允许被破坏的方块** | 打开方块多选界面（详见 [选择界面](selection-screens.md)） |
| **完成** | 保存并关闭 |

### 铺设模式

| 控件 | 说明 |
|------|------|
| **☑ 自适应生物群系** | 单选：根据生物群系自动选方块 |
| **☑ 选择自然方块: [名称]** | 单选：打开地形方块选择界面，指定一种方块 |
| **完成** | 保存并关闭 |

### 平滑模式

| 控件 | 说明 |
|------|------|
| **☑ 标准平滑** | 四种变体单选（悬停查看 tooltip） |
| **☑ 自适应平滑** | |
| **☑ 平滑提升** | |
| **☑ 平滑降低** | |
| **平滑强度 / 抬升降低深度** 滑动条 | 0.1–1.0；提升/降低模式下标签变为「抬升/降低深度」 |
| **完成** | 保存并关闭 |

### 表面粗糙

| 控件 | 范围 | 说明 |
|------|------|------|
| **粗糙强度** 滑动条 | 0.1–2.0 | 噪声起伏峰值 |
| **平滑强度（重塑）** 滑动条 | 0–1 | 加噪声前的平滑基准程度 |
| **自动缩放** 开关 | 开/关 | 默认开；关闭后显示下方高级参数 |
| **噪声频率** 滑动条 | 0.01–0.15 | 仅自动缩放关闭时可见 |
| **噪声持久性** 滑动条 | 0.1–0.9 | 同上（UI 滑动条范围；手动编辑 JSON 时服务端会钳制到 0.05–0.95） |
| **噪声八度数** 滑动条 | 1–6 | 同上 |
| **重置** 按钮 | — | 恢复所有参数为默认值 |
| **完成** | — | 保存并关闭 |

### 表层转换

| 控件 | 说明 |
|------|------|
| 方块行（最多 5 行） | 每行：方块图标 + 占比滑动条 + 删除按钮；点击图标可更换方块 |
| **分布模式** 循环按钮 | 自然斑块 / 随机散布 |
| **允许人工方块** 开关 | 开/关 |
| **添加方块** | 打开地形方块选择界面（未满 5 种时显示；已满 5 种时隐藏） |
| **归一化** | 均分所有方块占比（2 种及以上时显示；满 5 种时与 **完成** 并排） |
| **完成** | 保存并关闭 |

### 撒骨粉

| 控件 | 说明 |
|------|------|
| 提示文字 | 「撒骨粉模式暂时不需要配置」 |
| **完成** | 保存并关闭 |

### 批量种植

| 控件 | 说明 |
|------|------|
| **种植类型** 循环按钮 | 树木 / 花朵 / 草类 / 自定义（草类无额外选项） |
| **树种** 循环按钮 | 仅「树木」时显示：橡树、云杉、白桦、丛林、金合欢、深色橡木、生物群系自适应 |
| **花组** 循环按钮 | 仅「花朵」时显示：平原花卉、森林花卉、全部花卉、生物群系自适应 |
| **选择植物类型** 按钮 | 仅「自定义」时显示，打开植物多选界面 |
| **种植密度** 滑动条 | 10–100%（滑动条显示 0–100%，保存时钳制不低于 10%） |
| **团簇大小** 滑动条 | 值越大植物越分散，越小越集中 |
| **完成** | 保存并关闭 |

### 水岸处理

| 控件 | 说明 |
|------|------|
| **水岸类型** 循环按钮 | 沙滩 / 堤岸 / 自适应 / 泥泞 / 岩石 / 自定义 |
| **水岸宽度** 滑动条 | 1–10 格 |
| **启用植物种植** 开关 | 非自定义类型时显示 |
| **选择方块 / 选择植物** 按钮 | 仅「自定义」类型时显示，各占半宽 |
| **植被密度** 滑动条 | 0–100%；自定义类型始终显示，其他类型在启用植被时显示 |
| **在标高以上操作** 复选框 | 需非「标高不限」模式 |
| **在标高以下操作** 复选框 | 同上；与「以上」互斥 |
| **完成** | 保存并关闭 |

## 标高配置子面板

| 控件 | 说明 |
|------|------|
| **跟随玩家标高** | 单选 |
| **锁定玩家标高** | 单选：锁定当前脚下 Y |
| **标高不限** | 单选：默认 |

---

## 保存行为

| 操作 | 行为 |
|------|------|
| 主界面 **保存并关闭** | 写入 `pushdozer_config.json` 并同步到服务端 |
| 多数模式子面板 **完成** | 立即写入文件并显示「已保存」提示 |
| **批量种植** 子面板 **完成** | 仅关闭子面板（滑动条/类型切换已实时更新内存配置，但不单独写文件） |
| **水岸处理** 子面板 **完成** | 写入文件（无单独的成功提示） |

- 多人游戏中，配置通过 `ConfigSyncPayload` 同步到服务端（仅你自己的副本）
- 配置 **不会** 广播给其他玩家
