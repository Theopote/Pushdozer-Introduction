# 方块与植物选择界面

Pushdozer 提供 4 种选择界面，用于配置挖掘白名单、铺设/表层转换方块、自定义植物和水岸方块。

---

## 通用操作

所有选择界面共享以下交互：

| 操作 | 说明 |
|------|------|
| **搜索框** | 输入方块名称过滤列表 |
| **分类标签** | 顶部按钮切换方块分类 |
| **翻页** | 上一页 / 下一页浏览大量方块 |
| **点击方块** | 选中或取消选中（多选界面）/ 选中（单选界面） |
| **确认** | 保存选择并返回配置界面 |

---

## 1. 方块选择（挖掘白名单）

**入口**：挖掘模式 Config → **选择允许被破坏的方块**

**标题**：选择允许被破坏的方块

**选择方式**：多选

**底部按钮**：

| 按钮 | 功能 |
|------|------|
| 全选 | 选中当前可见列表中的所有方块 |
| 取消全选 | 清除所有选择 |
| 确认 | 保存白名单并返回 |

**分类列表**（27 类）：

| 分类 | 包含示例 |
|------|----------|
| 地形方块 | 石头、泥土、沙砾、深板岩等 |
| 矿石 | 各类矿石及深层变种 |
| 木材 | 各树种原木、去皮原木 |
| 门与活板门 | 木门、铁门、活板门 |
| 树叶 | 各树种树叶 |
| 植物与花朵 | 草、花、藤蔓 |
| 农作物 | 小麦、胡萝卜、西瓜等 |
| 菌类 | 蘑菇、菌丝 |
| 珊瑚 | 各类珊瑚及珊瑚块 |
| 下界方块 | 下界岩、灵魂沙、下界疣等 |
| 楼梯与台阶 | 各材质楼梯、台阶 |
| 栅栏与墙 | 栅栏、墙 |
| 按钮与压力板 | 各材质按钮、压力板 |
| 铜 | 铜块及氧化变种 |
| 紫水晶 | 紫水晶块、芽 |
| 贵重方块 | 金块、钻石块、信标等 |
| 红石 | 红石粉、中继器、活塞等 |
| 装饰方块 | 书架、画、旗帜等 |
| 染色方块 | 染色玻璃、陶瓦、混凝土 |
| 功能性方块 | 工作台、熔炉、箱子等 |
| 头颅 | 各类生物头颅 |
| 铁轨 | 各类铁轨 |
| 洞穴装饰 | 滴水石、孢子花等 |
| 流体 | 水、岩浆（默认在忽略列表中，通常不会被破坏） |
| 砖与瓦 | 砖块、石英块等 |
| 技术性方块 | 命令方块、结构方块等 |
| 杂项 | 未归入以上分类的方块 |

> **重要**：默认白名单为空。首次使用挖掘模式前必须在此界面选择至少一种方块。

## 2. 地形方块选择（铺设 / 表层转换）

**入口**：

- 铺设模式 Config → **选择自然方块**
- 表层转换 Config → 点击方块图标 / **添加方块**

**标题**：选择地形方块

**选择方式**：单选

**底部按钮**：确定 / 取消

**分类列表**（15 类）：

| 分类 | 说明 |
|------|------|
| 流体 | 水、岩浆等 |
| 地形方块 | 自然地形相关方块 |
| 冰与雪 | 冰、雪块、细雪等 |
| 矿石 | 各类矿石 |
| 铜 | 铜相关方块 |
| 木材 | 原木类 |
| 树叶 | 树叶类 |
| 生物方块 | 草方块、菌丝、灵魂沙等 |
| 楼梯与台阶 | 自然/半自然材质 |
| 染色方块 | 染色类 |
| 功能性方块 | 部分可用作地表的方块 |
| 发光方块 | 萤石、海晶灯等 |
| 装饰方块 | 装饰性自然方块 |
| 红石 | 红石相关 |
| 杂项 | 其他 |

> 此界面仅包含适合作为地形/地表的方块，不含容器和复杂方块实体。

## 3. 实体方块选择（水岸自定义）

**入口**：水岸处理 Config → 水岸类型选 **自定义** → **选择方块**

**标题**：实体方块选择

**选择方式**：多选

**底部按钮**：全选 / 取消全选 / 确认

**分类列表**（15 类）：

| 分类 | 说明 |
|------|------|
| 流体 | 水、岩浆 |
| 地形方块 | 基础地形 |
| 冰与雪 | 冰雪类 |
| 矿石 | 矿石类 |
| 铜 | 铜类 |
| 木材 | 木材类 |
| 树叶 | 树叶（含水岸适用品种） |
| 生物方块 | 生物相关地表 |
| 楼梯与台阶 | 半砖类 |
| 染色方块 | 染色类 |
| 功能性方块 | 箱子、熔炉等功能方块 |
| 发光方块 | 发光类 |
| 装饰方块 | 装饰类 |
| 红stone | 红石类 |
| 杂项 | 其他 |

> 此界面侧重功能性/实体方块，用于自定义水岸材质组合。

## 4. 植物选择（批量种植 / 水岸）

**入口**：

- 批量种植 Config → 种植类型选 **自定义** → **选择植物类型**
- 水岸处理 Config → 自定义类型 → **选择植物**

**标题**：选择植物

**选择方式**：多选

**分类列表**（16 类）：

| 分类 | 包含 |
|------|------|
| 全部植物 | 所有可选植物 |
| 树苗 | 各树种树苗 |
| 小型花朵 | 蒲公英、罂粟等 |
| 大型植物 | 向日葵、丁香等 |
| 草类和蕨类 | 草、蕨、高草 |
| 蘑菇 | 各类蘑菇 |
| 农作物 | 小麦、胡萝卜等 |
| 水生植物 | 海草、海带等 |
| 珊瑚 | 珊瑚类 |
| 下界植物 | 下界疣、垂泪藤等 |
| 洞穴植物 | 孢子花、垂根等 |
| 藤蔓植物 | 藤蔓、发光浆果等 |
| 末地植物 |  chorus 相关 |
| 盆栽 | 盆栽植物 |
| 特殊植物 | 特殊品种 |
| 其他 | 未分类植物 |

**操作**：

- 顶部搜索框过滤植物名称
- 点击分类按钮切换类别
- 点击植物图标切换选中状态
- 确认后返回配置面板

## 选择技巧

1. **挖掘常用组合**：地形 + 矿石 + 木材，按需追加
2. **表层转换**：先用单种方块测试效果，再逐步添加并 **归一化** 占比
3. **自定义种植**：在目标生物群系中测试，避免选到无法生长的植物
4. **搜索**：输入英文方块 ID 或中文名（取决于游戏语言设置）均可过滤
