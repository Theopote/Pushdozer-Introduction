# 入门指南

> 快速查阅快捷键和默认值：[速查表](cheatsheet.md)

## 安装要求

| 组件 | 版本要求 |
|------|----------|
| Minecraft | 1.21.11 |
| Fabric Loader | ≥ 0.18.2 |
| Fabric API | 对应 1.21.11 版本 |
| Java | 21（开发与运行均需 JDK 21） |
| 可选 | ModMenu（在模组列表中快速跳转链接） |

### 安装步骤

1. 安装 [Fabric 模组加载器](https://fabricmc.net/use/)
2. 下载并安装 [Fabric API](https://modrinth.com/mod/fabric-api)
3. 从 [Modrinth](https://modrinth.com/mod/pushdozer)（推荐）或 [GitHub Releases](https://github.com/Theopote/Pushdozer_Mod/releases) 下载 Pushdozer **v1.1.2**
4. 将 JAR 文件放入 `.minecraft/mods` 文件夹
5. 启动游戏（客户端或专用服务器均可）

> **注意**：请从 Modrinth 或 GitHub Releases 下载正式安装包，不要使用非官方来源的旧版 JAR。

## 首次使用

1. 进入创造模式，在物品栏 **Tools（工具）** 分组中找到 **推土机**
2. 将推土机放入快捷栏并手持
3. 按 `K` 键打开配置界面（可在 **选项 → 控制 → 推土机** 中修改快捷键）
4. 在配置界面中选择工作模式、笔刷形状和参数
5. **右键点击**目标位置执行操作

## 配置界面概览

按 `K` 打开配置界面，主要区域从上到下：

| 区域 | 说明 |
|------|------|
| **笔刷形状** | 选择 8 种几何体之一，点击 **Config** 调整尺寸（1–64） |
| **工作模式** | 选择 8 种模式之一，点击 **Config** 打开模式专属设置 |
| **显示模式** | 切换笔刷预览方式（线框 / 点云 / 表面 / 不显示） |
| **最大操作距离** | 滑动条或 `↑`/`↓` 调整（1–99，默认 20） |
| **标高配置** | 设置标高限制模式 |
| **保存并关闭** | 保存设置并关闭界面 |

也可通过 ModMenu 模组列表中的 Pushdozer 按钮进入配置界面。

## 交互条件

手持推土机（**主手或副手**）时，所有快捷键均可响应，包括 `K` 打开配置界面。也可通过 ModMenu 进入配置（无需手持工具）。

| 操作类型 | 主手 | 副手 |
|----------|------|------|
| 快捷键（K/G/U/V/↑↓/Ctrl+Z/Y） | ✓ | ✓ |
| 右键执行操作 | ✓ | ✓ |

## 基础快捷键

快捷键仅在主手或副手持有推土机时响应，可在 Minecraft 控制设置中自定义。

| 按键 | 功能 |
|------|------|
| `K` | 打开/关闭配置界面 |
| `G` | 循环切换工作模式 |
| `U` | 循环切换笔刷几何体（8 种） |
| `V` | 循环切换显示模式（线框 → 点云 → 表面 → 不显示 → …） |
| `Ctrl+Z` | 撤销上一步操作 |
| `Ctrl+Y` | 重做操作 |
| `↑` / `↓` | 增加 / 减少最大操作距离 |

> **提示**：右键是执行操作的唯一方式。快捷键仅用于切换设置，不会直接触发地形修改。

## 5 分钟快速上手

以下是一条连贯的入门流程，帮你在 5 分钟内完成第一次地形编辑：

| 步骤 | 操作 |
|------|------|
| 1. 获取工具 | 创造模式 → 物品栏 **Tools** 分组 → 拿取 **推土机** |
| 2. 打开配置 | 主手或副手持有推土机，按 `K` 打开配置界面 |
| 3. 选择模式 | 点击 **挖掘**，再点 **Config** → **选择允许被破坏的方块**，勾选泥土、石头等 |
| 4. 设置笔刷 | 笔刷选 **长方体**，尺寸约 8×8×3；标高选 **锁定玩家标高** |
| 5. 预览效果 | 按 `V` 切换到 **线框** 显示（默认已是线框），移动视角观察笔刷范围 |
| 6. 执行操作 | **右键** 点击目标地面——方块被清除 |
| 7. 撤销 | 按 `Ctrl+Z` 撤销；不满意可调整参数后重做 |

完成后可继续探索：

- 换 **水岸处理** 做沙滩 → 详见 [水岸预设](shoreline.md)

更多分步场景见 [操作教程](workflows.md)。
