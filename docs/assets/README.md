# Pushdozer 文档图片资源

本目录存放用户文档的截图与示意图。

## 目录结构

| 子目录 | 用途 |
|--------|------|
| `modes/` | 8 种工作模式的操作前 / 预览 / 操作后截图 |
| `shapes/` | 8 种笔刷几何体预览与效果截图 |
| `workflows/` | 实战教程分步截图 |

## 截图规范

每个主要功能至少 3 张：

1. **操作前** — 原始地形，标注即将使用的模式与笔刷参数
2. **笔刷预览** — 线框/点云/表面预览可见，标注关键参数
3. **操作后** — 完成效果，与操作前同视角对比

优先拍摄顺序见 [界面视觉指南 · 截图清单](../zh/visual-guide.md#截图清单)。

> 占位 SVG 文件标注了待替换为真实游戏内截图的位置。
