# 笔刷几何体

Pushdozer 提供 8 种笔刷几何体。在配置界面点击 **笔刷形状** 按钮直接选择，或按 `U` 键循环切换。

**循环顺序**：球体 → 长方体 → 正八面体 → 圆柱体 → 圆锥体 → 椭球体 → 正四面体 → 三棱柱

所有尺寸滑动条范围均为 **1–64 格**（尺寸参数，非最终覆盖直径）。点击 **Config** 打开对应子面板调整。

## 空间示意（侧视）

```
        圆锥体              圆柱体（Y轴竖直）        长方体
          /\                  |===|              +-------+
         /  \                 |   |              |       |
        /    \                |   |              |       |
       /______\               |___|              +-------+
     底面半径+高度           半径+高度          长×宽×高
```

> **圆柱体方向**：沿 **Y 轴竖直**延伸，**不随玩家视角旋转**。水平通道请用长方体；竖井/圆形竖向空间用圆柱体。

---

## 球体（Sphere）

| 项目 | 说明 |
|------|------|
| **参数** | `sphereRadius`（半径） |
| **形状** | 以目标点为中心的球形范围 |
| **覆盖** | 半径 R → 直径 2R（R=64 时直径 128） |
| **适用** | 山丘、洞穴、平滑过渡、批量种植 |

## 长方体（Box）

| 项目 | 说明 |
|------|------|
| **参数** | `length`（X）、`width`（Z）、`boxHeight`（Y） |
| **形状** | 轴对齐矩形范围（不旋转） |
| **适用** | 地基、平台、**水平隧道**、大面积平整 |

## 正八面体（Octahedron）

| 项目 | 说明 |
|------|------|
| **参数** | 半径 |
| **形状** | 钻石形立体，上下对称 |
| **适用** | 尖峰地形、特殊造型 |

## 圆柱体（Cylinder）

| 项目 | 说明 |
|------|------|
| **参数** | `cylinderRadius`、`cylinderHeight` |
| **形状** | **Y 轴竖直**圆柱（不可旋转） |
| **适用** | 竖井、塔基、圆形竖向空间；**不适合**水平圆形隧道 |

## 圆锥体（Cone）

| 项目 | 说明 |
|------|------|
| **参数** | 半径（底面）、高度 |
| **形状** | 底宽顶窄的锥体 |
| **适用** | 火山锥、金字塔形地形 |

## 椭球体（Ellipsoid）

| 项目 | 说明 |
|------|------|
| **参数** | 长度（X 轴半径）、宽度（Z 轴半径）、高度（Y 轴半径） |
| **形状** | 三轴可独立拉伸的椭球 |
| **适用** | 扁平或高耸的自然山丘 |

## 正四面体（Tetrahedron）

| 项目 | 说明 |
|------|------|
| **参数** | 边长 |
| **形状** | 金字塔形四面体 |
| **适用** | 尖顶地形、特殊几何造型 |

## 三棱柱（Triangular Prism）

| 项目 | 说明 |
|------|------|
| **参数** | 边长（三角形底边）、高度 |
| **形状** | 等边三角形截面的柱体 |
| **适用** | 楔形地形、三角基座 |

---

## 选择建议

| 需求 | 推荐几何体 |
|------|-----------|
| 快速平整大面积 | 长方体 |
| 自然山丘/洞穴 | 球体、椭球体 |
| 竖向挖掘 | 圆柱体 |
| 尖顶山峰 | 圆锥体、正四面体 |
| 规则建筑基础 | 长方体、三棱柱 |
| 植被种植 | 球体（自然分布） |
| 水岸处理 | 长方体或球体（沿岸边移动） |

---

## 性能提示

- 笔刷体积 ≈ 各轴尺寸之积（或几何公式），越大影响方块越多
- 建议从小尺寸开始测试，确认效果后再增大
- 多人服务器校验笔刷 **尺寸参数**（非最终覆盖直径）：各轴/半径参数须在 1–64 范围内；球体半径 64 时实际覆盖直径可达 128 格
- 大体积笔刷配合 **不显示** 预览模式可减轻客户端负担
