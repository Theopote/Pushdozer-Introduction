# 操作教程

按步骤完成的典型地形编辑任务。每篇教程列出推荐配置，可按需调整。

---

## 1. 平整建筑用地

**目标**：清除指定高度以上的方块，得到水平基底。

| 步骤 | 操作 |
|------|------|
| 1 | 工作模式 → **挖掘** |
| 2 | Config → **选择允许被破坏的方块**，勾选泥土、石头、草方块、沙砾等 |
| 3 | 笔刷 → **长方体**，长度/宽度覆盖施工区域，高度 3–5 |
| 4 | 标高 → **锁定玩家标高**（站在目标水平面上切换） |
| 5 | 显示 → **线框**，确认范围 |
| 6 | 右键逐段清除 |

**提示**：若只想去掉表层，缩小高度并仅选择草方块/泥土。

---

## 2. 挖掘隧道

**目标**：水平或略向下延伸的通道。

| 步骤 | 操作 |
|------|------|
| 1 | 工作模式 → **挖掘** |
| 2 | 选择可破坏方块：石头、深板岩、泥土等 |
| 3 | 笔刷 → **长方体**（长 3–5，宽 3–5，高 3） |
| 4 | 标高 → **标高不限** |
| 5 | 操作距离 → 适当增大（30–40） |
| 6 | 面向隧道方向，边走边右键 |

**提示**：水平通道请用 **长方体**。圆柱体沿 Y 轴竖直延伸、不随视角旋转，连续水平操作只会产生多个竖柱交叠，适合 **竖井、圆形竖向空间**，不适合标准水平圆形隧道。

---

## 3. 填平低洼 / 铺设平台

**目标**：填补空洞或创建人工地面。

| 步骤 | 操作 |
|------|------|
| 1 | 工作模式 → **铺设** |
| 2 | 选择 **自适应生物群系**（自动匹配环境）或指定方块（如石头） |
| 3 | 笔刷 → **长方体**，高度 1–3 |
| 4 | 标高 → **锁定玩家标高** |
| 5 | 右键填充低洼区域 |

---

## 4. 山体整形与自然化

**目标**：将粗糙山形修顺并增加自然起伏。

| 阶段 | 模式 | 配置建议 |
|------|------|----------|
| 粗修 | 挖掘 + 铺设 | 大球体/长方体，标高不限 |
| 整平 | 平滑 → **标准平滑** | 强度 0.6–0.8，中等球体 |
| 保形 | 平滑 → **自适应平滑** | 强度 0.3–0.5，保留山脊 |
| 自然化 | 表面粗糙 | 粗糙 0.4，重塑 0.3，自动缩放开 |
| 绿化 | 批量种植 / 撒骨粉 | 树木或草类，密度 30% |

---

## 5. 混合材质地表（表层转换）

**目标**：草地与泥土/粗泥自然斑驳，如自然草甸。

| 步骤 | 操作 |
|------|------|
| 1 | 工作模式 → **表层转换** |
| 2 | 添加方块：草方块 60%、泥土 30%、粗泥 10% |
| 3 | 点击 **归一化** |
| 4 | 分布 → **自然斑块** |
| 5 | 笔刷 → 球体或长方体，中等尺寸 |
| 6 | 多次右键覆盖区域，边界重叠以消除接缝 |

---

## 6. 创建沙滩

**目标**：湖泊或海洋边缘的沙子过渡。

| 步骤 | 操作 |
|------|------|
| 1 | 工作模式 → **水岸处理** |
| 2 | 水岸类型 → **沙滩** |
| 3 | 宽度 → 3–5 |
| 4 | 启用植被，密度 10–20% |
| 5 | 笔刷 → 长方体（宽覆盖岸线，高 1–2） |
| 6 | 沿水边移动并右键 |

**效果**：默认沙子→泥土过渡；沙漠为红沙；雪地生物群系为雪块/冰。

详见 [水岸预设详解](shoreline.md)。

---

## 7. 河岸边坡（堤岸）

| 步骤 | 操作 |
|------|------|
| 1 | 水岸类型 → **堤岸** |
| 2 | 宽度 4–6 |
| 3 | 笔刷长方体沿河流推进 |

**效果**：默认圆石→沙砾；山地为石头/圆石；恶地为砂岩。

---

## 8. 自适应水岸（推荐默认）

| 步骤 | 操作 |
|------|------|
| 1 | 水岸类型 → **自适应**（默认） |
| 2 | 根据生物群系自动选择沙滩/堤岸/泥泞等风格 |
| 3 | 不确定用什么预设时优先选此项 |

---

## 9. 自定义水岸

**目标**：完全控制岸边方块和植物。

| 步骤 | 操作 |
|------|------|
| 1 | 水岸类型 → **自定义** |
| 2 | **选择方块** → 多选（如沙子、砾石、石头） |
| 3 | **选择植物** → 多选（如枯木、海草、草丛） |
| 4 | 设置植被密度 |
| 5 | 笔刷沿水边右键 |

---

## 10. 快速造林

| 步骤 | 操作 |
|------|------|
| 1 | 工作模式 → **批量种植** |
| 2 | 种植类型 → **树木**，树种 → **生物群系自适应** |
| 3 | 密度 30–50%，团簇适中 |
| 4 | 球体笔刷，右键多次 |

**注意**：确保地面为泥土/草方块等可生长表面。

---

## 11. 花田布置

| 步骤 | 操作 |
|------|------|
| 1 | 种植类型 → **花朵** |
| 2 | 花组 → **平原花卉** 或 **生物群系自适应** |
| 3 | 密度 40–60%，团簇偏小（更分散） |
| 4 | 扁平长方体笔刷（高 1–2），右键 |

---

## 12. 局部抬升地基

| 步骤 | 操作 |
|------|------|
| 1 | 平滑 → **提升** |
| 2 | 深度 0.4–0.6 |
| 3 | 小球体笔刷，在目标点多次右键叠加 |

---

## 13. 快速绿化（撒骨粉）

| 步骤 | 操作 |
|------|------|
| 1 | 工作模式 → **撒骨粉**（无需 Config） |
| 2 | 笔刷覆盖草地区域 |
| 3 | 右键催熟草、花、作物 |

---

## 14. 撤销误操作

| 步骤 | 操作 |
|------|------|
| 1 | 手持推土机 |
| 2 | `Ctrl+Z` 撤销（最多 30 步） |
| 3 | 若提示冲突，等待当前区域编辑完成后再试 |

---

## 组合技巧

- **锁定标高 + 长方体 + 挖掘**：精确水平切割
- **表层转换斑块 + 小笔刷 + 多次重叠**：消除材质边界
- **自适应平滑 → 表面粗糙**：先整平再加微起伏
- **铺设填底 → 表层转换**：先统一基底再换材质
