# 使用技巧

## 标准操作流程

1. 手持推土机（主手或副手均可执行操作；打开配置需主手）
2. 按 `K` 打开配置界面
3. 选择 **工作模式** → 点击 **Config** 调整模式参数
4. 选择 **笔刷形状** → 点击 **Config** 调整尺寸
5. 设置 **标高模式**（如需水平面或分层操作）
6. 确认 **显示模式** 和 **操作距离**
7. 点击 **保存并关闭**
8. 对准目标 **右键** 执行

---

## 撤销与重做

- 每名玩家独立 **30 步**历史
- `Ctrl+Z` 撤销，`Ctrl+Y` 重做
- 两次操作间隔至少 300 ms
- 撤销仅影响自己的操作；多人游戏中同步到所有客户端
- **建议**：大范围操作前在小区域测试，确认效果后再扩大

## 场景工作流

### 平整建筑用地

1. 挖掘模式 → 选择可破坏方块（泥土、石头、草方块等）
2. 长方体笔刷，适当的长×宽，较小的高度
3. **锁定玩家标高**
4. 右键逐段推进

### 填平低洼 / 铺设平台

1. 铺设模式 → **自适应生物群系** 或指定方块
2. 长方体笔刷
3. **锁定玩家标高**
4. 右键填充

### 山体整形

1. **粗加工**：大球体或长方体 + 挖掘/铺设
2. **整平**：标准平滑，强度 0.5–0.8
3. **保形修饰**：自适应平滑，强度 0.3–0.5
4. **自然化**：表面粗糙，低强度（0.3–0.5）+ 自动缩放开启
5. **绿化**：批量种植或撒骨粉

### 混合材质地表

1. 表层转换 → 添加 2–3 种方块（如草方块、泥土、粗泥）
2. 调整占比 → **归一化**
3. 分布模式选 **自然斑块**
4. 用小笔刷多次右键，避免边界过于整齐

### 河岸边坡

1. 水岸处理 → 类型 **堤岸** 或 **自适应**
2. 宽度 3–5，启用植被
3. 长方体笔刷沿河道移动右键
4. 如需限制高度：标高模式设为 **跟随玩家** 或 **自定义**

### 快速造林

1. 批量种植 → 树木 → 生物群系自适应
2. 球体笔刷，密度 30–50%，团簇适中
3. 右键多次覆盖区域

### 局部抬升 / 下切

1. 平滑模式 → **提升** 或 **降低**
2. 小球体笔刷
3. 深度 0.3–0.6，多次右键叠加效果

## 建筑辅助

- **锁定标高 + 长方体**：完美水平地基
- **表层转换 + 斑块模式**：石路与草地自然交界
- **平滑变体**：大面积用标准，保形用自适应，微调用提升/降低
- **标高不限 + 圆柱体**：精确竖井

---

## 性能优化

- 笔刷从 1 开始逐步增大
- 优先 **线框** 预览；需要体积感时用 **表面**
- 大范围操作分批执行
- 多人服务器上操作前通知队友
- 遇到卡顿时：减小笔刷 → 切换 **不显示** → 降低操作距离

---

## 多人协作

- 每人配置独立，互不影响
- 地形修改实时同步
- 避免多人同时在重叠区域操作
- 撤销只回退自己的历史

---

## 配置管理

- 路径：`config/pushdozer_config.json`
- 优先使用游戏内界面修改
- 旧版扁平 JSON 会自动迁移
- 备份配置文件可在不同世界间复用设置
