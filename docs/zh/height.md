# 标高系统

标高系统控制 Pushdozer 操作时的垂直高度限制，在配置界面的 **标高配置** 面板中设置。

---

## 标高切面示意（侧视）

```
参考标高 ─────────── Y=64 ───────────
              挖掘 ↑ 可在此以上
              铺设 ↓ 可在此以下

标高不限：    挖掘与铺设均不受 Y 限制（全高度）
跟随玩家：    参考 Y = 玩家脚下，随移动更新
锁定/自定义： 参考 Y = lockedHeight，固定不变
```

---

## 四种标高模式

### 标高不限（NO_LIMIT）

- 不限制操作高度
- 所有工作模式均不受 Y 坐标约束
- 适合复杂三维编辑、隧道、竖井

### 跟随玩家标高（FOLLOW_PLAYER）

- 参考 Y = 玩家当前脚下方块高度
- 随玩家移动实时更新
- 适合边走边编辑

### 锁定玩家标高（LOCKED_ONCE）

- 切换时捕获当前脚下 Y，写入 `lockedHeight`
- 之后不再随玩家移动
- 适合固定水平面施工

### 自定义标高（CUSTOM）

- 通过滑动条手动设置 Y（−64 至 320）
- 写入 `lockedHeight`
- 适合多层建筑指定楼层

---

## 各模式标高规则对照表

### 挖掘模式

| 标高模式 | 可破坏的方块 Y 范围 |
|----------|---------------------|
| 标高不限 | 任意 |
| 跟随玩家 | Y ≥ 玩家脚下 Y |
| 锁定 / 自定义 | Y ≥ lockedHeight + 1 |

### 铺设模式

| 标高模式 | 可放置的方块 Y 范围 |
|----------|---------------------|
| 标高不限 | 任意 |
| 跟随玩家 | Y ≤ 玩家脚下 Y − 1 |
| 锁定 / 自定义 | Y ≤ lockedHeight |

### 平滑 / 表面粗糙 / 表层转换 / 撒骨粉 / 批量种植

| 标高模式 | 行为 |
|----------|------|
| 全部 | **不受标高限制**（标高仅影响上述挖掘/铺设/水岸） |

### 水岸处理

| 标高模式 | 额外开关 |
|----------|----------|
| 标高不限 | 「以上/以下操作」**不可用** |
| 跟随 / 锁定 / 自定义 | 可启用「在标高以上」或「在标高以下」（互斥） |

> 超出标高范围的方块被 **静默跳过**，不会弹出聊天提示。

---

## 水岸标高限制

| 开关 | 行为 |
|------|------|
| **在标高以上操作** | 水岸处理仅作用于参考标高以上的方块 |
| **在标高以下操作** | 水岸处理仅作用于参考标高以下的方块 |

- 两者 **互斥**
- 需先设置非「标高不限」的标高模式
- 悬停不可用开关时会提示需先设置参考标高

---

## 典型用法

| 场景 | 推荐模式 | 配合模式 |
|------|----------|----------|
| 创建水平地面 | 锁定玩家标高 | 挖掘（切高）或 铺设（填低） |
| 只挖脚下以上 | 跟随玩家 | 挖掘 |
| 挖掘地下空间 | 标高不限 | 挖掘 |
| 在 Y=64 楼层施工 | 自定义 Y=64 | 挖掘或铺设 |
| 水岸仅水面附近 | 跟随玩家 + 以下操作 | 水岸处理 |
| 水岸不影响水下 | 自定义 + 以上操作 | 水岸处理 |

---

## 操作示例

### 精确水平切割

1. 站在目标水平面
2. 标高 → **锁定玩家标高**
3. 挖掘模式 + 长方体（高度 1–3）
4. 右键 → 仅清除锁定高度以上的方块

### 填平到 foot level

1. 标高 → **锁定玩家标高**
2. 铺设模式
3. 右键 → 方块填充到锁定高度及以下
