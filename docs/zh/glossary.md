# 名词解释

本文档汇总 Pushdozer 中常见的游戏内术语与概念，便于查阅。

---

## 核心概念

| 术语 | 说明 |
|------|------|
| **推土机 / Pushdozer** | 模组提供的地形编辑工具物品，创造模式 Tools 分组中获取，不可堆叠 |
| **笔刷（Brush）** | 一次操作影响的立体空间范围，由几何体类型和尺寸参数决定 |
| **工作模式（Work Mode）** | 右键执行的操作类型，如挖掘、铺设、平滑等，共 8 种 |
| **几何体（Geometry）** | 笔刷的三维形状，共 8 种（球体、长方体等） |
| **标高（Height）** | 垂直方向的参考高度，用于限制挖掘/铺设/水岸的作用层 |
| **操作距离（Operation Distance）** | 玩家视线能触及目标的最大方块距离（1–99，默认 20） |
| **预览（Preview）** | 客户端显示的笔刷范围指示，不影响实际操作 |
| **白名单（Block Whitelist）** | 挖掘模式下允许破坏的方块列表；默认为空 |
| **撤销 / 重做（Undo / Redo）** | 回退或恢复最近的地形操作，每名玩家独立 30 步 |

---

## 工作模式相关

| 术语 | 说明 |
|------|------|
| **挖掘模式（Excavate）** | 将笔刷内白名单方块替换为空气 |
| **铺设模式（Place）** | 在笔刷内填充自然方块 |
| **平滑模式（Smooth）** | 重塑笔刷内地形高度，含 4 种变体 |
| **标准平滑（Standard Smooth）** | 高斯模糊整平，单次变化较大 |
| **自适应平滑（Adaptive Smooth）** | 多尺度双边滤波，保留大地形轮廓 |
| **平滑提升 / 降低（Raise / Lower）** | 在笔刷中心形成隆起或凹陷 |
| **表面粗糙（Surface Roughen）** | 为地表添加 Perlin 噪声起伏 |
| **表层转换（Surface Convert）** | 按比例替换地表列方块，不改变高度 |
| **撒骨粉（Bone Meal）** | 对笔刷内植物施加骨粉效果 |
| **批量种植（Batch Plant）** | 在笔刷内批量生成植物 |
| **水岸处理（Shoreline Process）** | 在水边混合表层材质，可选种植植被 |

---

## 表层与噪声

| 术语 | 说明 |
|------|------|
| **自然斑块（Patchy）** | 表层转换的分布模式，用固定种子噪声形成连贯材质块 |
| **随机散布（Scatter）** | 表层转换的分布模式，每列独立随机 |
| **人工方块（Artificial Surfaces）** | 玩家放置或非自然生成的固体方块；默认不参与表层转换 |
| **粗糙强度（Roughness Strength）** | 表面粗糙模式的噪声峰值（1.0 ≈ ±5 格） |
| **平滑重塑强度（Smoothing Intensity）** | 加噪声前向平滑基准靠拢的程度（0–1） |
| **噪声频率（Noise Frequency）** | 噪声纹理的细节尺度，高 = 细碎，低 = 平缓 |
| **噪声持久性（Noise Persistence）** | 多层噪声的相对权重 |
| **噪声八度数（Noise Octaves）** | 噪声叠加层数 |
| **自动缩放（Auto Scale）** | 根据笔刷半径自动调整噪声参数 |

---

## 种植与水岸

| 术语 | 说明 |
|------|------|
| **种植密度（Plant Density）** | 批量种植时单位面积内的植物比例（10–100%） |
| **团簇大小（Cluster Scale）** | 植物分布的聚集程度；值越大越分散 |
| **生物群系自适应（Biome Adaptive）** | 根据当前生物群系自动选择树种或花组 |
| **水岸宽度（Shoreline Width）** | 从水边向陆地方向的过渡距离（1–10 格） |
| **植被密度（Vegetation Density）** | 水岸处理时沿岸边种植植物的比例 |

---

## 标高系统

| 术语 | 说明 |
|------|------|
| **标高不限（No Limit）** | 不限制垂直操作范围 |
| **跟随玩家（Follow Player）** | 参考高度随玩家脚下 Y 坐标实时更新 |
| **锁定玩家标高（Lock Once）** | 切换时锁定当前脚下 Y，之后不再跟随 |
| **自定义标高（Custom）** | 通过滑动条手动指定 Y 坐标（−64 至 320） |
| **参考标高** | 挖掘/铺设/水岸标高限制所依据的 Y 值 |

---

## 显示与界面

| 术语 | 说明 |
|------|------|
| **线框（Wireframe）** | 以轮廓线显示笔刷边界，性能最好 |
| **点云（Point Cloud）** | 以采样点显示笔刷内表面方块 |
| **表面（Surface）** | 以半透明面显示笔刷外表面体积 |
| **不显示（None）** | 关闭预览 |
| **Config 子面板** | 点击配置界面中 **Config** 按钮弹出的模式/几何体专属设置 |
| **确认 / 完成（Done）** | 子面板底部按钮，保存当前面板设置并关闭 |

---

## 多人游戏

| 术语 | 说明 |
|------|------|
| **服务端权威（Server Authoritative）** | 所有方块修改在服务端执行并同步 |
| **区域锁定（Region Busy）** | 目标区块正被其他编辑占用，新操作被拒绝 |
| **独立配置** | 每名玩家的模式、笔刷、标高等设置互不影响 |
| **ConfigSyncPayload** | 客户端保存配置后同步到服务端的网络包 |

---

## 配置文件

| 术语 | 说明 |
|------|------|
| **pushdozer_config.json** | 配置文件路径：`.minecraft/config/pushdozer_config.json` |
| **brush** | 配置节：笔刷几何、标高、可破坏方块列表 |
| **surface** | 配置节：铺设、平滑、粗糙、表层转换参数 |
| **planting** | 配置节：批量种植参数 |
| **shoreline** | 配置节：水岸处理参数 |
| **preview** | 配置节：显示模式与操作距离 |
