# 水岸预设详解

水岸处理模式只替换 **表层方块**，不改变高度。效果从水边向内陆衰减，受 **水岸宽度** 控制。

---

## 通用机制

1. 检测笔刷范围内靠近水的地表列
2. 按离水距离（0 至宽度值）计算材质混合概率
3. 距水越近，主材质概率越高；越远越接近副材质
4. 可选：按 **植被密度** 在合适地面种植植物
5. 笔刷范围外的方块不受影响

> 仅笔刷内的方块可被修改；宽度控制距水多远开始混合。

---

## 沙滩（Beach）

**适用**：海洋、湖泊、河流的 sandy 风格岸线。

| 生物群系 | 主材质 → 副材质 |
|----------|----------------|
| 默认（温带等） | 沙子 → 泥土 |
| 恶地 | 红沙 → 红砂岩 |
| 雪地类 | 雪块 → 冰 |

**植被**：海草、枯木等（取决于地面类型与密度设置）。

---

## 堤岸（Embankment）

**适用**：河流、运河的结构性边坡。

| 生物群系 | 主材质 → 副材质 |
|----------|----------------|
| 默认 | 圆石 → 沙砾 |
| 山地 | 石头 → 圆石 |
| 恶地 | 砂岩 → 平滑砂岩 |
| 雪地类 | 雪块 → packed ice |

**植被**：草丛、蕨类等陆地植物。

---

## 自适应（Adaptive）

**适用**：不确定选哪种预设时的首选。

根据当前生物群系特征自动调用沙滩、堤岸、泥泞或岩石逻辑，例如：

- 海洋/沙滩生物群系 → 偏沙滩风格
- 山地 → 偏岩石/堤岸
- 沼泽 → 偏泥泞
- 沙漠 → 红沙相关材质

---

## 泥泞（Muddy）

**适用**：沼泽、湿地、慢流河边缘。

| 特点 | 说明 |
|------|------|
| 主材质 | 泥土、灰化土 |
| 副材质 | 砂土、粘土 |
| 植被 | 沼泽植物（如睡莲附近植被、高草） |

---

## 岩石（Rocky）

**适用**：山地湖泊、峡谷河流、基岩感岸线。

| 特点 | 说明 |
|------|------|
| 主材质 | 石头、深板岩 |
| 副材质 | 圆石、沙砾 |
| 植被 | 稀疏，偏枯木、蕨类 |

---

## 自定义（Custom）

完全由玩家选择：

| 控件 | 说明 |
|------|------|
| **选择方块** | 多选参与混合的方块（实体方块选择界面） |
| **选择植物** | 多选可种植植物 |
| **植被密度** | 始终可调 |

未选择方块时，操作可能无效果。

---

## 标高限制

| 开关 | 行为 |
|------|------|
| **在标高以上操作** | 仅处理参考标高以上的方块 |
| **在标高以下操作** | 仅处理参考标高以下的方块 |

**前置条件**：标高模式不能为「标高不限」。需先设跟随玩家、锁定或自定义标高。

两者互斥。

---

## 推荐参数

| 场景 | 类型 | 宽度 | 植被 |
|------|------|------|------|
| 大海沙滩 | 沙滩 / 自适应 | 4–6 | 开，10–15% |
| 内陆湖泊 | 沙滩 | 3–4 | 开，15% |
| 河流 | 堤岸 | 4–5 | 开，20% |
| 沼泽 | 泥泞 | 5–7 | 开，25–30% |
| 山地湖泊 | 岩石 | 3–4 | 关或低密度 |
| 完全自定义 | 自定义 | 按需 | 按需 |

---

## 操作技巧

1. 笔刷 **高度设小**（1–2），避免误改远离水面的高地
2. 用 **线框** 预览确认范围后再执行
3. 长岸线分段右键，每段重叠 1–2 格避免断带
4. 先处理材质，满意后再用 **批量种植** 补充大型植被
