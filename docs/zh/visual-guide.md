## 1. 获取推土机

```
创造模式 → 物品栏 → Tools（工具）分组 → Pushdozer（推土机）
```

| 说明 | 详情 |
|------|------|
| 堆叠 | 不可堆叠（最大 1） |
| 手持 | 主手打开配置；主手或副手均可执行操作 |

## 2. 主配置界面（按 K）

```
┌─────────────────────────────────┐
│     Pushdozer Configuration     │
├─────────────────────────────────┤
│ [Brush Shape: Box        ▼] [Config] │
│ [Work Mode: Excavate     ▼] [Config] │
│ [Display Mode: Wireframe      ]      │
│ Max Distance: ████████░░ 20          │
│ [Height Config]                      │
│ [Save and Close]                     │
└─────────────────────────────────┘
```

| 区域 | 快捷键 | 说明 |
|------|--------|------|
| 笔刷形状 ▼ | `U` | 展开 8 种几何体列表 |
| Config（笔刷） | — | 打开尺寸滑动条子面板 |
| 工作模式 ▼ | `G` | 展开 8 种模式列表 |
| Config（模式） | — | 打开模式专属设置 |
| 显示模式 | `V` | 循环切换预览 |
| 距离滑动条 | `↑`/`↓` | 1–99 |
| 标高配置 | — | 四种标高模式 |
| 保存并关闭 | — | 写入配置并同步 |

## 8. 游戏内预览

| 模式 | 视觉效果 |
|------|----------|
| 线框 | 白色轮廓线框 |
| 点云 | 笔刷内表面采样点 |
| 表面 | 半透明白色外表面 |
| 不显示 | 无预览 |

预览仅客户端显示，手持推土机且非「不显示」时可见。

## 9. 操作反馈

| 反馈类型 | 位置 | 示例 |
|----------|------|------|
| 模式切换 | 动作栏（屏幕下方） | 「工作模式已切换为：平滑」 |
| 标高切换 | 动作栏 | 「标高模式已切换为：锁定玩家标高 (Y=64)」 |
| 操作拒绝 | 动作栏 | 「目标区域正在处理中…」 |
| 笔刷预览 | 世界中 | 线框/点云/表面覆盖在目标位置 |

## 10. 控制设置

```
选项 → 控制 → Pushdozer
```

| 默认键 | 功能 |
|--------|------|
| K | 打开配置 |
| G | 切换工作模式 |
| U | 切换笔刷形状 |
| V | 切换显示模式 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| ↑ / ↓ | 操作距离 |
