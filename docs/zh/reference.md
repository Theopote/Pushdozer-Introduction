## 目标定位机制

Pushdozer 通过玩家视线确定操作中心：

1. 从玩家眼睛位置沿视线方向发射射线
2. 最大距离 = 当前 **最大操作距离** 设置
3. **击中方块**：以该方块位置为笔刷中心
4. **未击中方块或超出距离**：取视线方向上最远可达点（向下取整为方块坐标）

笔刷几何体以该中心为基准构建，再应用标高过滤规则。

## 撤销与重做

| 项目 | 说明 |
|------|------|
| 快捷键 | `Ctrl+Z` 撤销，`Ctrl+Y` 重做 |
| 历史深度 | 每名玩家在每个维度独立保存 30 步 |
| 冷却 | 两次撤销/重做之间至少间隔 300 ms |
| 新操作 | 清除重做栈 |
| 验证 | 若目标位置当前方块与记录不符，跳过该位置 |
| 失败 | 区域被占用或所有位置均无效时，显示冲突提示 |
| 多人 | 服务端执行，变更同步到所有客户端 |

## 各模式行为要点

### 挖掘

- 仅破坏白名单中的方块
- 跳过：空气、不可破坏方块（硬度 &lt; 0）、忽略列表中的方块（默认含水、岩浆、空气）
- 标高过滤见 [标高系统](height.md)

### 铺设

- 替换空气和可替换的软方块
- 自适应模式根据生物群系选择方块（如熔岩旁铺石头、沙旁铺砂岩）
- 标高过滤见 [标高系统](height.md)

### 平滑

- 根据变体调用不同算法（高斯 / 双边 / 方向性隆起或凹陷）
- 仅修改笔刷范围内的高度，不改变方块类型（表层方块可能随高度变化）

### 表面粗糙

- 先按平滑重塑强度向基准靠拢，再叠加噪声
- 强度 1.0 约 ±5 格峰值（材质系数另计）

### 表层转换

- 仅替换地表列方块，不改变 Y 坐标
- 斑块模式：固定种子 Perlin 噪声决定材质归属
- 散布模式：每列独立随机
- 容器和方块实体始终受保护

### 撒骨粉

- 对笔刷内符合条件的植物施加骨粉
- 变更纳入撤销栈

### 批量种植

- 按密度和团簇参数在笔刷内生成植物
- 树木模式调用 Minecraft 树生成器
- 自定义列表为空时使用默认植物

### 水岸处理

- 检测笔刷范围内的水边，从水面向内陆混合材质
- **不改变高度**，仅替换表层方块
- 预设类型根据生物群系调整（如沙漠红沙、雪地雪块）
- 自适应类型自动选择最佳预设

## 获取工具

1. 进入 **创造模式**
2. 打开物品栏，切换到 **Tools（工具）** 分组
3. 找到 **推土机（Pushdozer）** 物品
4. 不可堆叠，每名玩家可持有一个

也可通过 ModMenu 快速访问模组信息和配置入口。
