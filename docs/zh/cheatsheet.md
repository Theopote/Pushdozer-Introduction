# 速查表

一页速查 Pushdozer 常用操作与默认值。完整参数、游戏内提示与机制说明见 [参考手册](reference.md)。

---

## 交互条件

| 操作 | 主手 | 副手 |
|------|------|------|
| 快捷键 G/U/V/↑↓/Ctrl+Z/Y | ✓ | ✓ |
| 配置界面 K | ✓ | ✗ |
| 右键执行 | ✓ | ✓ |

## 快捷键

| 键 | 功能 |
|----|------|
| `K` | 配置界面（仅主手） |
| `G` | 循环工作模式 |
| `U` | 循环笔刷形状 |
| `V` | 循环显示模式 |
| `↑`/`↓` | 操作距离 ±1 |
| `Ctrl+Z` | 撤销（30 步） |
| `Ctrl+Y` | 重做 |
| **右键** | 执行操作（主手或副手） |

---

## 工作模式（G 循环顺序）

| # | 模式 | 一句话 |
|---|------|--------|
| 1 | 挖掘 | 清除白名单方块 |
| 2 | 铺设 | 填充自然方块 |
| 3 | 平滑 | 4 变体重塑高度 |
| 4 | 表面粗糙 | 加噪声起伏 |
| 5 | 表层转换 | 按比例换材质 |
| 6 | 撒骨粉 | 催熟植物 |
| 7 | 批量种植 | 批量生成植物 |
| 8 | 水岸处理 | 水边材质过渡 |

---

## 笔刷形状（U 循环顺序）

球体 → 长方体 → 正八面体 → 圆柱体 → 圆锥体 → 椭球体 → 正四面体 → 三棱柱

尺寸：**1–64**

---

## 显示模式（V 循环）

线框 → 点云 → 表面 → 不显示

---

## 标高速查

| 模式 | 挖掘 | 铺设 |
|------|------|------|
| 不限 | 任意 | 任意 |
| 跟随玩家 | Y ≥ 脚Y | Y ≤ 脚Y−1 |
| 锁定/自定义 | Y ≥ 锁定+1 | Y ≤ 锁定 |

---

## 平滑变体

| 变体 | 用途 | 强度建议 |
|------|------|----------|
| 标准 | 大面积整平 | 0.5–0.8 |
| 自适应 | 保形去噪 | 0.3–0.5 |
| 提升 | 局部抬高 | 0.3–0.6 |
| 降低 | 局部下切 | 0.3–0.6 |

---

## 关键默认值

| 项 | 值 |
|----|-----|
| 模式 | 挖掘 |
| 几何 | 长方体 5³ |
| 显示 | 线框 |
| 距离 | 20 |
| 标高 | 不限 |
| 挖掘白名单 | **空** |
| 平滑 | 自适应 0.5 |
| 水岸 | 自适应，宽 3 |

---

## 常见问题速查

| 问题 | 解决 |
|------|------|
| 挖掘无效 | 选可破坏方块 |
| 无预览 | 显示模式≠不显示，且手持工具 |
| 无法撤销 | 等 300ms；检查区域是否忙 |
| 多人无效果 | 检查笔刷 ≤64；看动作栏提示 |
