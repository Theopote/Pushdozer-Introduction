# 更新日志

Pushdozer 用户文档对应模组版本 **v1.1.1**（Minecraft 1.21.11）。

完整开发变更见 [GitHub CHANGELOG](https://github.com/theopote/pushdozer/blob/main/CHANGELOG.md)。

---

## v1.1.1（2026-07-14）

### 新增

- **表面（Surface）** 预览模式：以半透明白色面显示笔刷外表面体积
- 集中式 **HandlerRegistry** 地形工具处理器管理
- 处理器注册表与撤销/重做并发相关单元测试

### 变更

- 预览模式循环顺序：**线框 → 点云 → 表面 → 不显示**
- 表面预览采用贪心网格合并，提升大体积笔刷预览性能
- 处理器注册从静态字段重构为注册表模式

### 修复

- 撤销管理器中的无效 Unicode 字符导致编译错误
- 处理器接口引用缺失问题

---

## v1.1.0（2026）

### 新增

- 支持 **Minecraft 1.21.11**
- 嵌套配置结构（`brush` / `surface` / `planting` / `shoreline` / `preview`）
- 旧版扁平 JSON 配置自动迁移
- GameTest 覆盖撤销同步行为
- 大批量方块操作的跨 tick 调度

### 变更

- 需要 **Java 21**
- 需要 **Fabric Loader ≥ 0.18.2**
