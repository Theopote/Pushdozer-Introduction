# 工作模式

Pushdozer 提供 **8 种**工作模式，按 `G` 键循环切换。每种模式在配置界面中都有独立的 **Config** 子面板。

> **执行方式**：手持推土机，对准目标位置 **右键点击**。快捷键只切换设置，不会直接修改地形。

---

## 挖掘模式（Excavate）

清除笔刷范围内的方块。

### 基本操作

- 通过 **选择允许被破坏的方块** 配置白名单
- 仅破坏白名单中的方块；不可破坏方块（硬度 &lt; 0）始终跳过
- 默认白名单为 **空** — 首次使用前必须至少选择一种方块，否则挖掘不会有任何效果

### 标高限制

| 标高模式 | 可挖掘范围 |
|----------|-----------|
| 标高不限 | 任意高度 |
| 跟随玩家 | Y ≥ 玩家脚下高度 |
| 锁定 / 自定义 | Y ≥ 锁定标高 + 1 |

超出标高范围的方块会被 **静默跳过**，不会弹出提示。

**适用场景**：平整地形、挖掘隧道、清除特定方块、创建地下空间。

## 铺设模式（Place）

在笔刷范围内填充自然方块。

### 铺设方式

| 方式 | 说明 |
|------|------|
| **自适应生物群系** | 根据当前生物群系与地表上下文自动选择合适方块（如草原铺草方块、沙漠铺沙子） |
| **选择自然方块** | 手动指定一种自然方块，点击按钮进入方块选择界面 |

### 标高限制

| 标高模式 | 可铺设范围 |
|----------|-----------|
| 标高不限 | 任意高度 |
| 跟随玩家 | Y ≤ 玩家脚下高度 − 1 |
| 锁定 / 自定义 | Y ≤ 锁定标高 |

配合 **锁定玩家标高** 可快速创建水平地面。

**适用场景**：填补空地、创建平台、恢复被破坏的地表。

---

## 平滑模式（Smooth）

在笔刷范围内重塑地形高度。配置面板提供 **4 种平滑变体**（单选）：

| 变体 | 说明 |
|------|------|
| **标准平滑** | 空间高斯模糊，消除小起伏并填平凹陷。单次变化幅度较大，适合一般地形整平 |
| **自适应平滑** | 多尺度双边滤波，去除细碎噪声，同时保留山体与大地形轮廓 |
| **提升** | 在笔刷中心形成高斯隆起并与周围混合，适合局部抬升 |
| **降低** | 在笔刷中心形成凹陷并与周围混合，适合局部下切 |

### 强度参数

- **平滑强度**（标准 / 自适应）：0.1–1.0，控制每次操作的平滑力度
- **抬升/降低深度**（提升 / 降低）：0.1–1.0，控制单次最大高度变化比例

鼠标悬停在各变体按钮上可查看详细说明。

**适用场景**：整平地基、柔化山坡过渡、局部抬升或下切、自然化人工地形。

## 表面粗糙（Surface Roughen）

为过于平整的地表添加自然起伏纹理（会改变高度）。

### 参数说明

| 参数 | 说明 |
|------|------|
| **粗糙强度** | 控制噪声起伏峰值（强度 1.0 ≈ ±5 格，材质系数另计） |
| **平滑强度（重塑）** | 在加噪声前将地形向平滑基准重塑（0 = 保留原貌，1 = 完全平滑重塑） |
| **自动缩放** | 默认开启，根据笔刷半径自动调整噪声参数 |

关闭 **自动缩放** 后，可手动调整：

- **噪声频率** — 高频率产生细碎起伏，低频率产生平缓起伏
- **噪声持久性** — 控制多层噪声的相对强度
- **噪声八度数** — 噪声层数，更多层数增加复杂度但可能影响性能

面板底部提供 **重置** 按钮恢复默认值。

**适用场景**：让平整的人工地形看起来更自然、创建微起伏地貌。

---

## 表层转换（Surface Convert）

将笔刷范围内地表列的方块按配置比例替换为多种材质（**不改变高度**）。

### 方块配置

- 最多添加 **5 种**方块，各自设置占比
- **添加方块** / **归一化** 按钮管理比例
- 默认：草方块 100%

### 分布模式

| 模式 | 说明 |
|------|------|
| **自然斑块** | 使用固定种子噪声形成连贯的材质斑块，效果更自然 |
| **随机散布** | 每列独立随机选择，分布更均匀 |

### 其他选项

- **允许人工方块**：默认关闭。开启后，非自然固体方块也可被转换；容器与方块实体始终受保护
- 若配置中没有有效目标方块，操作会被跳过并提示

**适用场景**：混合地表（草地与泥土斑驳）、材质过渡、路径与周边地表融合。

---

## 撒骨粉（Bone Meal）

在笔刷范围内对植物施加骨粉效果，促进生长。

- 无需额外配置
- 对草、花、作物、树苗等有效
- 变更纳入撤销/重做历史

**适用场景**：快速绿化、催熟作物、恢复植被。

---

## 批量种植（Batch Plant）

在笔刷范围内批量种植植物。

### 种植类型

| 类型 | 说明 |
|------|------|
| **树木** | 可选树种（橡树、云杉、白桦等）或 **生物群系自适应** |
| **花朵** | 可选花组（平原花卉、森林花卉等）或 **生物群系自适应** |
| **草类** | 种植草、蕨类等低矮植被 |
| **自定义** | 从植物列表中自由选择 |

### 其他参数

- **种植密度** — 控制单位面积内的植物数量（10–100%）
- **团簇大小** — 控制植物分布的聚集程度（高值更分散，低值更集中）

**适用场景**：快速造林、布置花田、恢复生态。

---

## 水岸处理（Shoreline Process）

在水域边缘创建自然的水岸材质过渡（**只替换表层方块，不改变高度**）。

### 水岸类型

| 类型 | 说明 |
|------|------|
| **沙滩** | 铺设沙子，适合海洋和湖泊 |
| **堤岸** | 泥土/草方块过渡 |
| **自适应** | 根据生物群系自动选择（如沙漠红沙、雪地雪块） |
| **泥泞** | 沼泽风格泥泞水岸 |
| **岩石** | 岩石质水岸 |
| **自定义** | 自选方块与植物 |

### 其他参数

- **水岸宽度** — 距水边的水平过渡距离（1–10 格）
- **启用植物种植** / **植被密度** — 在水岸区域自动种植适合的植物（自定义类型除外）
- **在标高以上/以下操作** — 需先设置非「标高不限」的标高模式；两者互斥

**适用场景**：创建沙滩、河岸边坡、湖泊生态、沼泽水岸。
